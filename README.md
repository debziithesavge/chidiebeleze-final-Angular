To run this angular project:
First you need to install the "npm install" command in your terminal to install all the necessary npm packages the project needs to run. This is a one time process for each angular app folder you want to run. 
Second step after the installation of the npm packages the command "npm run start" can be used to run the application. Upon a successful compilation of files a localhost serve is created usually "http://localhost:4200" by default which can be ran in the copied and pasted into your browser to view the application that has been created.
